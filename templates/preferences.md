# pemstudy card preferences
#
# Plain-English instructions for how you want your flashcards made. sync and triage
# read this file every run and apply it on top of the plugin's defaults.
#
# A PREFERENCE is an uncommented bullet line (starts with "- "). Everything else —
# these comment lines and the "##" section headings — is ignored. Uncomment an
# example below to turn it on, or add your own bullets. An all-commented file (the
# default) changes nothing.
#
# Edit by chatting ("from now on, keep cards to one line") or with /pemstudy:prefs.

## Style
# - Keep card fronts and backs terse — one line each where possible.
# - Prefer cloze deletions for doses, thresholds, lab values, and numeric cutoffs.
# - When a well-known mnemonic exists, put it in the Extra field.
# - Phrase fronts as the exam would ask (next-best-step, first-line vs contraindicated).

## Content
# - Only include drug doses when the boards actually test them.
# - Always flag adult-derived numbers on a pediatric card.
# - Prefer image-identification cards for rashes, ECGs, and X-rays.

## Skip
# - Don't card pure epidemiology/statistics trivia.
# - Skip anything I tag with "skip" in my notes.
